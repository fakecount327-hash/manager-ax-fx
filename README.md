# PWA — manager-dashboard-18

هذا المشروع يحتوي على لوحة `manager-dashboard-18.html` فقط كواجهة التطبيق.

الملفات:
- manager-dashboard-18.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png

## GitHub Pages
ارفع الملفات كما هي إلى Repository واحد، ثم فعّل GitHub Pages من:
Settings → Pages → Deploy from branch

بعد النشر افتح:
`https://USERNAME.github.io/REPOSITORY/manager-dashboard-18.html`

ومن Microsoft Edge اختر تثبيت التطبيق.

## مدة التشغيل الحالية
الملف مضبوط على 10 أيام من أول استخدام في نفس المتصفح، باستخدام التخزين المحلي.
مهم: هذا ليس نظام ترخيص مركزي؛ مسح بيانات المتصفح قد يعيد العداد.

## عند تعديل ملفات الموقع
بعد تعديل `manager-dashboard-18.html` على GitHub، غيّر رقم نسخة الكاش في `sw.js`، مثل:
manager-dashboard-v1 → manager-dashboard-v2
ثم اعمل Commit.
